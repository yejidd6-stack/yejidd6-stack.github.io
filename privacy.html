개인정보처리방침 · Privacy Policy

시행일 · Effective date: 2026-11-22

1. 이 문서가 다루는 서비스

이 방침은 "Kkomings Uploader"(이하 "앱")에 적용됩니다. 앱은 채널 운영자 본인이 만든 영상을 본인의 YouTube 채널에 업로드하기 위해 운영자 본인만 사용하는 개인용 도구입니다.

2. 수집·이용하는 정보

  • Google 계정 인증 토큰(OAuth): 운영자 본인 채널에 영상을 업로드하기 위해서만 사용합니다.
  • YouTube 채널 기본 정보(채널 ID, 채널 이름): 업로드할 채널이 맞는지 확인하는 데만 사용합니다.

앱은 위 정보를 운영자의 컴퓨터에만 저장하며, 외부 서버로 전송하거나 제3자에게 제공·판매하지 않습니다. 광고나 분석 목적으로 사용하지 않습니다.

3. 사용하는 API와 권한

앱은 YouTube API 서비스를 사용합니다. 요청하는 권한은 영상 업로드(youtube.upload)와 채널 정보 읽기(youtube.readonly)뿐입니다. YouTube API 서비스를 사용함으로써 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.

4. 보관 기간과 삭제

인증 토큰은 운영자가 삭제하거나 권한을 해제할 때까지 운영자의 컴퓨터에 보관됩니다. 언제든지 Google 계정의 보안 설정(서드 파티 액세스)에서 앱 권한을 해제할 수 있으며, 해제하면 앱은 더 이상 계정에 접근할 수 없습니다.

5. 문의

문의는 YouTube 채널 "꼬밍즈" 또는 "Kkomings"의 채널 정보를 통해 해 주세요.

English summary

"Kkomings Uploader" is a personal tool used only by the channel owner to upload their own videos to their own YouTube channels. It uses YouTube API Services with the youtube.upload and youtube.readonly scopes. OAuth tokens and basic channel info are stored only on the owner's computer, are never sent to any other server, and are never shared, sold, or used for advertising or analytics. By using YouTube API Services, the YouTube Terms of Service and the Google Privacy Policy also apply. Access can be revoked at any time at Google Account permissions. Contact: via the "Kkomings" YouTube channel's About page.
